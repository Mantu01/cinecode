# Contributing to Cinecode

Thank you for your interest in contributing to Cinecode!

## Code Conventions
- Code is written in strict TypeScript.
- Follow Conventional Commits: `feat:`, `fix:`, `perf:`, `security:`, `docs:`, `chore:`.
- No extraneous comments in code — write self-documenting code with single-line comments only where strictly necessary.

## Development Workflow
1. Install dependencies:
   ```bash
   pnpm install
   ```
2. Build the engine:
   ```bash
   pnpm run build
   ```
3. Typecheck codebase:
   ```bash
   pnpm run typecheck
   ```
