# Security Policy

## Supported Versions
| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
We take the security of Cinecode seriously. If you discover a security vulnerability, please do NOT create a public GitHub issue.

Please report security vulnerabilities directly to:
**security@cinecode.dev**

### Response SLA
- Initial acknowledgement within 24 hours.
- Vulnerability triage and assessment within 72 hours.
- Coordinated release patch within 14 days of confirmed exploit.
